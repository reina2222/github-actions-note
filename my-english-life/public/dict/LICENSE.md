# 収録辞書データのライセンス

このフォルダ（public/dict/）のデータは、以下のデータを加工して作ったものです。
Wiktionary・Octanove 由来の部分は **CC BY-SA 4.0** で配布します（同じライセンスで自由に再利用できます）。

- **Wiktionary（英語版）**（kaikki.org / wiktextract）
  - https://en.wiktionary.org/
  - ライセンス: CC BY-SA 4.0 / GFDL
  - 用途: 定義・品詞・発音記号・例文（作例のみ）・類義語・反意語・翻訳表の日本語訳・スラング等の表示
- **Wiktionary（日本語版）**（kaikki.org / wiktextract）
  - https://ja.wiktionary.org/
  - ライセンス: CC BY-SA 4.0 / GFDL
  - 用途: 日本語の語義
- **The CEFR-J Wordlist Version 1.5**（Compiled by Yukio Tono, Tokyo University of Foreign Studies. Retrieved from http://www.cefr-j.org/download.html）
  - https://github.com/openlanguageprofiles/olp-en-cefrj
  - ライセンス: 研究・商用とも無料（出典の明記が条件）。著作権: 東京外国語大学 投野研究室
  - 用途: CEFR A1〜B2
- **Octanove Vocabulary Profile C1/C2 1.0**（Octanove Labs）
  - https://github.com/openlanguageprofiles/olp-en-cefrj
  - ライセンス: CC BY-SA 4.0
  - 用途: CEFR C1〜C2
- **wordfreq**（Robyn Speer ほか）
  - https://github.com/rspeer/wordfreq
  - ライセンス: データ: CC BY-SA 4.0
  - 用途: 収録する語の選定（頻度順）。頻度の数値は収録していません

変更点: 元データから、学習に使う項目だけを抜き出して形式を変えています（古語・まれな語義・活用形・固有名詞・引用文・音声は除外）。内容の書き換えや翻訳はしていません。

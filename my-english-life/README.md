# My English Life 2.0

> 覚えた英語を、使える英語に。

日本人の英語学習者が、覚えたい英単語・フレーズを登録し、意味・発音・使い方を自分の単語帳にまとめ、
間隔反復（1・3・7・14・30・60日）で記憶に定着させる、**完全無料・AI 不使用**の PWA です。

- AI API（OpenAI / Anthropic / Gemini など）は一切使いません
- ログイン不要。データはこの端末のブラウザに保存（JSON でバックアップ・復元できます）
- 必要な環境変数はありません（Vercel の無料プランで公開できます）

## 動かす

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # lint + 型チェック + テスト + ビルド
```

## データ（`src/lib/schemas.ts`）

- **Entry（項目）**: 英単語 または フレーズ。発音記号、単語の CEFR（不明なら null＝レベル未設定）、類義語・対義語・言い換え・関連表現、表現の種類・地域、注意事項、タグ、メモ、**出典（user / dictionary / migrated）**
- **Sense（語義）**: 1つの項目に複数。品詞、日本語の意味（空欄可）、英語の定義、例文、メモ
- **Example（例文）**: 英文、日本語訳（空欄可）、**例文の CEFR（単語の CEFR とは別。不明なら null）**、出典
- 未収録の日本語訳・レベルを推測で埋めることはしません

## 復習（`src/lib/srs.ts`）

- 登録の翌日から。適応型: 覚えた＝間隔を延長（3→7→14→30→60日）／あやふや＝翌日／忘れた＝同じ回の最後にもう一度＋翌日、段階を最初から
- 固定間隔: 登録日から 1・3・7・14・30・60日目
- **習得済み** ＝「覚えた」が4回連続（「忘れた」「あやふや」で解除）
- 1日の上限 5 / 10 / 20 / 無制限（残りは翌日以降へ持ち越し）

## 保存とバックアップ（`src/lib/store/`）

- 保存先: localStorage `mel:data:v2`
- 1.x（AI 英作文アプリ）のデータ `mel:data:v1` は**削除しません**。初回起動時に `mel:backup:v1` にコピーしてから 2.0 の単語帳へ移します（サンプルとして入れたフレーズは移しません）
- マイページ → バックアップを保存（JSON）／取り込む（追加。重複は取り込まない）／旧版データを保存


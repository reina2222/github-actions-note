# 公開・更新の手順（GitHub + Vercel・無料）

## すでに公開している場合（1.x → 2.0 への更新）

2.0 では使わなくなったファイルがあります。GitHub に**古いファイルが残っているとビルドに失敗する**ので、先に削除してから新しいファイルを入れます。1つずつ進めてください。

### ステップ1：古いフォルダを削除する
GitHub のリポジトリを開き、次のフォルダをそれぞれ削除します。
1. `src` フォルダを開く → 右上の「…」→「Delete directory」→「Commit changes」
2. `supabase` フォルダも同じように削除（無い場合はとばす）
3. `tests` フォルダも同じように削除
4. `SETUP-AI.md` があれば、開いて右上の「…」→「Delete file」→「Commit changes」

※ ここで一度 Vercel のビルドが失敗しても問題ありません。ステップ2で直ります。

### ステップ2：新しいファイルをアップロードする
1. `my-english-life.zip` を解凍
2. GitHub で「Add file」→「Upload files」
   - 1回目：`src` **以外**の中身をすべてドラッグ →「Commit changes」
   - 2回目：もう一度「Upload files」→ `src` フォルダをドラッグ →「Commit changes」
3. Vercel が自動で公開し直します（2〜3分）

### ステップ3：使わなくなった設定を消す（任意）
Vercel →「Settings」→「Environment Variables」に `ANTHROPIC_API_KEY` や `NEXT_PUBLIC_SUPABASE_URL` などがあれば削除して構いません（2.0 では使いません）。
Supabase のプロジェクトを作っていた場合も、使わないので削除して構いません。

### 確認
アプリを開き、下のメニューが「ホーム・単語登録・カード学習・復習・マイページ」になっていれば完了です。
以前に保存したフレーズは、単語帳に「英作文から移行」のタグ付きで入っています。

## 初めて公開する場合
1. https://github.com で新しいリポジトリ（Private）を作り、上の「ステップ2」と同じようにアップロード
2. https://vercel.com →「Continue with GitHub」→ Hobby（無料）→「Add New → Project」→ リポジトリを Import →「Deploy」
3. 環境変数の設定は不要です

## スマホでアプリとして使う
- iPhone：Safari で開く → 共有 →「ホーム画面に追加」
- Android：Chrome で開く → メニュー →「アプリをインストール」

## データについて
データは各端末のブラウザに保存されます。機種変更やブラウザのデータ削除で消えるので、マイページの「バックアップを保存」をときどき使ってください。

## 収録辞書を作る（無料・GitHub Actions）

辞書データは、GitHub の無料機能「Actions」がインターネットからダウンロードして自動で作ります。
パソコンに大きなファイルをダウンロードする必要はありません。

### 最初に1回だけ: Actions に書き込みを許可する
1. GitHub のリポジトリを開く → 上の **Settings**
2. 左のメニュー **Actions** → **General**
3. いちばん下の **Workflow permissions** で **Read and write permissions** を選ぶ → **Save**

### 辞書を作る（1,000語 → 5,000語 → 10,000語 → 15,000語）
1. リポジトリの上の **Actions** タブを開く
2. 左の一覧から **収録辞書を作る** を選ぶ
3. 右の **Run workflow** → 語数（最初は **1000**）を選んで、緑の **Run workflow** を押す
4. 20〜40分ほどで緑のチェックになります。実行結果をクリックすると、日本語訳・CEFR の割合などの報告が表示されます
5. 完了すると `public/dict/` が自動でコミットされ、Vercel が自動で公開します

うまくいかないとき（赤い × になったとき）は、実行結果の画面を撮って送ってください。
